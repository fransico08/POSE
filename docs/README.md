# Hệ thống E-Commerce & CRM - Tài liệu (Docs)

## Giới thiệu
Thư mục lưu trữ toàn bộ tài liệu đặc tả, thiết kế, quy trình và hướng dẫn của dự án Hệ thống quản lý Thương mại điện tử tích hợp CRM dành cho SME.

## Danh sách tài liệu
- **Tài liệu Đặc tả Yêu cầu (SRS)**: `XÂY DỰNG HỆ THỐNG QUẢN LÝ THƯƠNG MẠI ĐIỆN TỬ TÍCH HỢP CRM HỖ TRỢ HOẠT ĐỘNG BÁN HÀNG VÀ CHĂM SÓC KHÁCH HÀNG CHO DOANH NGHIỆP SME.docx` chứa chi tiết về:
  - Bối cảnh và mục tiêu dự án (Kết hợp TMĐT và CRM).
  - Yêu cầu chức năng (Must Have, Should Have, Could Have).
  - Yêu cầu phi chức năng.
  - Sơ đồ Cơ sở dữ liệu (ERD) và Kiến trúc hệ thống.
  - Kế hoạch 6 Round, phân công nhiệm vụ và rủi ro.
  - Hướng phát triển lên Khóa luận tốt nghiệp (RFM, Predictive CLV, AI).
- **API Documentation**: Bản export đặc tả REST API thông qua Swagger (SpringDoc OpenAPI).
- **Thiết kế giao diện**: Các bản vẽ wireframe / UI/UX Mockup.
- **Tài liệu kiểm thử**: (Unit Test, Integration Test, Playwright, Postman, Pytest).
