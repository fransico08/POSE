# Evidence AI-10 — Công cụ đánh giá tín hiệu — 18/11/2026

## Phạm vi

Theo đề xuất DEC-28 (chờ Tài duyệt), profile `ai-eval` kiểm tra datasource trước khởi động và `data_directory` trước Flyway. Mỗi run có tổ chức đánh giá riêng, không user/hồ sơ nghiệp vụ; gọi SYSTEM qua SIGNAL_EXTRACT của Gateway và cùng schema, prompt, che dữ liệu, kiểm an toàn và lọc tín hiệu. Run không ghi `customer_signals`, suggestion hay Task. Profile không bật thì ứng dụng không chạy đánh giá.

Input và hướng dẫn: [định dạng](ai-10-eval-format.md), [runbook](ai-10-eval-runbook.md). Kiểm tra toàn bộ JSONL trước khi chạy: loại sai nhãn, ID trùng và JSON sai, chỉ nêu số dòng/lý do. Đầu ra ngoài repo không chứa nội dung tin; `run.json` ghi commit, hash, provider/model/prompt và cấu hình. Invocation dùng `subject_id` là run ID; UUID invocation xác định theo run và sample để đối chiếu và tránh gọi lặp khi resume.
