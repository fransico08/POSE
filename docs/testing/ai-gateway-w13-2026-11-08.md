# Evidence AI Gateway W13 — 08/11/2026

## Phạm vi và luồng

W12 AI-01 phần cấu hình của Tài và W13 AI-03; không làm bot, tunnel, kênh hội thoại, Copilot API/UI hay Signal. Nền `be5f05f`, JDK 25.0.2, Maven 3.9.15, PostgreSQL 18.3. Chỉ dùng cluster `127.0.0.1:54329` với guard `SHOW data_directory`; không kết nối Supabase hoặc PostgreSQL 5432.

```text
Cờ AI → permission → service đọc hồ sơ theo actor → che dữ liệu → budget → provider
       → ghi invocation transaction riêng → suggestion PROPOSED / trả trạng thái
```

| Trạng thái invocation | Ý nghĩa |
|---|---|
| `DISABLED` | AI tắt hoặc chọn Claude nhưng thiếu khóa |
| `BLOCKED_BUDGET` | Đã đạt hạn mức mềm của tổ chức trong tháng |
| `FAILED` | Provider từ chối hoặc lỗi; CRM tiếp tục |
| `SUCCEEDED` | Có kết quả và suggestion `PROPOSED` |

Suggestion được chuyển một lần từ `PROPOSED` sang `ACCEPTED`, `EDITED` hoặc `REJECTED`. Audit không lưu nội dung; bảng invocation chỉ có hash input đã che, số token, chi phí và metadata.

## Cấu hình và chi phí

SDK chính thức `com.anthropic:anthropic-java:3.2.0`; `claude-haiku-5-5`/effort `low` cho SIGNAL_EXTRACT, `claude-sonnet-5-5`/effort `medium` cho ba use case còn lại. Mặc định `enabled=false`, provider `mock`, 16.000 max output token, timeout 30 giây, một retry, budget 5 USD/tháng/tổ chức. Không cấu hình sampling hoặc tắt thinking. Theo bảng giá cấu hình, 1 triệu input + 1 triệu output token ước tính 0,60 USD với Haiku và 12 USD với Sonnet; đây là ước tính, không phải đối soát hóa đơn.

SDK 3.2.0 cung cấp `BetaFallbacksParam.ofDefault()` và beta message builder; Sonnet gửi fallback `default` với beta `server-side-fallback-2026-07-01`. Test chỉ dùng HTTP server giả trên loopback; chưa xác nhận tính năng được bật trên tài khoản Claude thật. SDK HTTP logging và OpenTelemetry được tắt để tránh phát tán nội dung và khóa.
